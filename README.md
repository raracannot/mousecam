# MouseCam — 跟随视口录屏 Demo（Windows）

录屏时同时记录鼠标轨迹，并额外产出一份「自动跟随鼠标的裁切视口」视频：
镜头平滑追随光标，快速移动时视口自动放大 1.5 倍以显示更多屏幕内容。
屏幕上始终有一个取景框 HUD，未录制时也能实时调参。

## 产物

| 文件 | 说明 |
|---|---|
| `dist/MouseCam.exe` | 主程序，**0.75 MB 单文件，静态 CRT，无运行时依赖** |
| `dist/ffmpeg.exe` | 编码后端（可替换为任意带 libx264 的构建） |

主程序不含任何三方运行时；H.264/H.265/VP9/ProRes/GIF 全部由 ffmpeg 子进程完成，
所以 exe 本体能压到 1MB 以内。分发时把两个文件放同一目录即可（便携）。

## 构建

```bat
build.bat
```

依赖：Visual Studio 2022（MSVC x64）+ Windows SDK。ImGui 已 vendored 在 `third_party/`。

## 运行

直接双击 `dist/MouseCam.exe`。

- `Ctrl+Alt+R` 开始/停止录制
- 录制产物在 `dist/captures/rec_<时间戳>/`：
  - `camera.mp4` — 跟随视口视频（导出格式由面板决定）
  - `master.mp4` — 全屏原始素材（H.264，用于换参数重新渲染）
  - `track.csv` — 鼠标轨迹（时间 / 坐标 / 按键，约 250Hz）
  - `meta.json` — 本次参数快照

调试用环境变量：

| 变量 | 作用 |
|---|---|
| `MC_LOG=1` | 写 `mousecam.log`（耗时、ffmpeg 启动结果） |
| `MC_NO_WDA=1` | 让 HUD 也进入屏幕采集（默认会被排除，仅调试用） |
| `MC_AUTOREC=1` / `MC_AUTOSTOP=N` | 无人值守自测：启动 2.5s 后开录，录 N 秒后退出 |
| `MC_SIZE=560x980` | 指定窗口初始尺寸（物理像素），用于排版测试 |

## 面板

- **滑块**：单击 → 原地变成输入框（不跳值）；双击 → 跳到点击位置；按住拖动 → 微调；悬停按 **退格 → 恢复默认值**（滑轨上的细白刻度就是默认值位置）
- **分段控件**：显示器 / 比例 / 帧率
- **导出格式**：MP4·H.264、MP4·H.264(NVENC)、MKV·H.265、WebM·VP9、GIF、MOV·ProRes
- 无边框窗口，拖动标题区移动，四边可拉伸

## 关键实现

**相机（`camera.cpp`）**
1. 光标位置先过 **One Euro 滤波**（低通截止频率随速度自适应）——静止时不抖，快移时不拖影；
2. 视口尺寸 = `输出宽度 / 缩放 × (1 + (放大倍数-1) × smoothstep(速度/阈值))`，扩张快、收缩慢（0.07s / 0.30s）避免来回"呼吸"；
3. 镜头中心用**临界阻尼弹簧**跟随（ζ=1，可调 Hz），并叠加按速度的前瞻偏移；
4. 相机每 4ms 更新一次，HUD 与录制读的是同一份状态——**所见即所得**。

**采集（`media.cpp`）**
- 首选 **DXGI Desktop Duplication**（GPU 采集），失败自动回落 GDI BitBlt（RDP/虚拟机/被占用时）；
- 处理器里做双线性重采样，源/目标尺寸相同时走整行 `memcpy` 快路径；
- 光标由程序自己合成（真实系统光标，按缩放做双线性 + alpha 混合）。

**编码**
- `ffmpeg` 子进程 + stdin `rawvideo bgra` 管道；
- 主片优先 `h264_nvenc`，无独显时回落 `libx264 ultrafast`；
- **CFR 时间戳补偿**：当采集跟不上目标帧率时补重复帧，保证成片时长 = 真实墙钟（否则会静默快放）。

## 实测（2560×1440 主屏 + 1280×720 视口，30fps）

| 阶段 | 优化前 (GDI) | 优化后 (DXGI) |
|---|---|---|
| 抓屏 | 25–38 ms | **1.9–4.8 ms** |
| 重采样 | 1.5–1.9 ms | 1.5–1.9 ms |
| 编码 | 9–31 ms | 9–13 ms |
| 整帧 | 36–72 ms | **13–19 ms** |
| 实际帧率 | 14–22 fps | **30.0 fps（锁目标）** |

## 已知限制

- 抓屏走整屏回读，4K60 需要再上 GPU 侧裁剪 + 硬件编码零拷贝；
- 音频尚未接入（WASAPI loopback + 麦克风混音、A/V 同步是独立一块）；
- 多屏跨屏跟随会切换视口，目前不做拼接；
- HDR / 独占全屏 / 受保护内容（DRM）未处理；
- 仅支持单次录制，没有剪辑时间线（可基于 `track.csv` 重渲染）。
